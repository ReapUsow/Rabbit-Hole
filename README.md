# Rabbit-Hole
A spiraling homelab repository documenting IT, virtualisation, infrastructure automation, and security configurations.
---

## 🐇 The "Rabbit Hole" Methodology

This repository is built on a modular experiment framework:

* **The Rabbit (Main Goal):** The core homelab objective, architecture, or primary deployment target.
* **The Holes (Sub-Sections):** The technical tangents, experimental setups, and deep-dives encountered along the way.

### Why This Structure?
Every "hole" represents a real-world testing branch. Whether an experiment yields a successful automation script or a completely broken configuration, documenting the process unfiltered shows how solutions are reached. This repo is built to showcase hands-on learning, iteration, and problem-solving without hiding the imperfections.

## 🕳️ The Holes (Experiments & Lab Sub-sections)

* 📁 **`01-virtualisation/`**: Proxmox VE configurations, VM templates, and resource allocation notes.
* 📁 **`02-containers/`**: Docker Compose templates, LXC setups, and service orchestrations.
* 📁 **`03-networking/`**: Virtual switches, firewall policies, and VLAN layouts.
* 📁 **`04-security-sandbox/`**: Hardening scripts, active directory labs, and security testing notes.
* 📁 **`05-automation/`**: Ansible playbooks and shell scripts for automated deployments.
